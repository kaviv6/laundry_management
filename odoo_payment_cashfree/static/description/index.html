Configure Webhook
  1. Log in to your Cashfree Merchant Dashboard.
  2. Go to Developers → Webhooks.
  3. Under the Payment Gateway section, click Add Webhook Endpoint, then enter your Odoo database URL followed by /payment/cashfree/webhook as the webhook endpoint.
    For example: https://example.odoo.com/payment/cashfree/webhook
  4. Select Version 2025-01-01 (the latest version currently supported in Odoo).
  5. Click on Test, then click on Continue to verify and save the webhook.
  6. Select the following events to be notified:
    • Success Payment
    • Failed Payment
    • Refund
    • User Dropped Payment

    7. Save the webhook configuration to allow Cashfree to send real-time transaction status updates to Odoo.

Configuration on Odoo

  1. Install the Cashfree Payment Gateway module from the Apps menu.
  2. Navigate to the Payment Providers menu in Odoo:
    • Accounting ‣ Configuration ‣ Payment Providers
    • Website ‣ Configuration ‣ Payment Providers
    • Sales ‣ Configuration ‣ Payment Providers
  3. Select the Cashfree provider and open the Credentials tab.
    • Enter your Client ID and Client Secret.
    • Set the environment to Test or Production based on your setup.
  4. Set the provider’s State to Enabled and save your configuration.

Once configured, the Cashfree payment methods (UPI, Cards, Net Banking, etc.) will appear automatically on your Odoo website checkout page, based on the settings defined in your Cashfree dashboard.
